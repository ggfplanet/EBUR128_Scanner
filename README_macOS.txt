WICHTIGER HINWEIS ZUR INSTALLATION (macOS)

Da der EBU R 128 Scanner eine spezialisierte Software ist, die nicht über den App Store vertrieben wird, muss die Ausführung beim ersten Start in den macOS-Systemeinstellungen manuell erlaubt werden.

Vorgehensweise für den ersten Start:

1. Ziehen Sie den "EBU R 128 Scanner" in Ihren Programme-Ordner.
2. Klicken Sie mit der RECHTEN Maustaste (oder Control-Klick) auf die App und wählen Sie "Öffnen".
3. Falls macOS den Start blockiert:
   - Öffnen Sie die "Systemeinstellungen" Ihres Macs.
   - Navigieren Sie zu "Datenschutz & Sicherheit".
   - Scrollen Sie nach unten zum Bereich "Sicherheit".
   - Dort finden Sie den Hinweis: "EBU R 128 Scanner wurde blockiert...".
   - Klicken Sie auf die Schaltfläche "Dennoch öffnen".
4. Bestätigen Sie den daraufhin erscheinenden Dialog erneut mit "Öffnen".

Dieser Vorgang ist nur einmalig beim ersten Start (oder nach einem Update) erforderlich.
